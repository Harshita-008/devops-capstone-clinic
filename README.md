# ClinicFlow: Clinic Appointment Management

ClinicFlow is a clinic appointment management system built as the final DevOps capstone project.
Front desk staff can register patients, manage doctors and book, complete or cancel appointments.

The project covers the full delivery path: application code, automated tests, Docker images,
a GitHub Actions pipeline with Trivy scanning, AWS infrastructure with Terraform, deployment to
Kubernetes with Helm, and monitoring with Prometheus and Grafana.

Full documentation is added as each part of the project is completed.
